# Gym Cloud Phase A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Gree cloud API client (sign in, list homes, list devices), platform-level `cloud` settings, and a probe command that prints the devices an account can see, without ever printing secrets.

**Architecture:** A new `src/cloud/cloudApi.ts` holds pure helpers (hashing, request signing, AES body encryption) and a small client class with an injectable `fetch`. A new `src/cloud/cloudProbe.ts` is a command-line entry point that reads the Homebridge config and prints a device table. Nothing in the running plugin uses the cloud code yet, so existing behaviour is unchanged.

**Tech Stack:** TypeScript 6, ES modules (`nodenext`), Node 22 built-ins only (`node:crypto`, global `fetch`, `node:fs`), Node test runner. No new npm dependencies.

**Protocol facts (from the reference):**

- Constants: `APP_ID = '4920681951525131286'`, `APP_HASH = '0fa513124aa97781d1f3f40d61ca1a89'`, body AES key `'#G$&^jgfujy6ujxt'` (AES-128-ECB, PKCS7 padding, base64).
- Region REST hosts:
  - `Australia`: `https://augrih.gree.com`
  - `China Mainland`: `https://grih.gree.com`
  - `East South Asia`: `https://hkgrih.gree.com`
  - `Europe`: `https://eugrih.gree.com`
  - `India`: `https://ingrih.gree.com`
  - `Middle East`: `https://megrih.gree.com`
  - `North American`: `https://nagrih.gree.com`
  - `Russia`: `https://rugrih.gree.com`
  - `South American`: `https://sagrih.gree.com`
- Timestamp `t` is UTC formatted `YYYY-MM-DD HH:MM:SS`; `r` is the Unix time in whole seconds.
- `vc = md5(APP_ID + '_' + APP_HASH + '_' + t + '_' + r)`.
- `datVc = md5(APP_HASH + '_' + values.join('_'))` where `values` are the payload values named by `hashProps`, in that order; an array value is its items joined with `_`.
- Request body object: `{ api: { appId, r, t, vc }, datVc, ...payload }`, JSON-stringified, AES encrypted, base64 encoded, sent as the raw POST body with headers `Content-Type: application/x-www-form-urlencoded`, `Gaen1: 5ac2bdf935bcca70`, `Charset: utf-8`.
- Response is JSON `{ enRes: '<base64>' }`; `enRes` decrypts (same key) to a JSON string.
- Password hash: `psw = md5(md5(md5(password) + password) + t)`.
- Sign in: `POST /App/UserLoginV2`, payload `{ psw, t, user }`, hashProps `['user', 'psw', 't']`. Decrypted reply has `uid` and `token` at top level, or inside `data`. A reply with `r` present and not 200 is a failure; its `msg` is the reason.
- Homes: `POST /App/GetHomes`, payload `{ token, uid }`, hashProps `['token', 'uid']`. Reply `{ home: [{ id, name }] }`.
- Devices: `POST /App/GetDevsInRoomsOfHomeV2`, payload `{ token, homeId, uid }`, hashProps `['token', 'uid', 'homeId']`. Reply `{ rooms: [{ devs: [{ name, mac, key, model, ver, online, pmac, mid }] }] }`.

**Interfaces to produce in `src/cloud/cloudApi.ts` (exact names):**

```ts
export const GREE_CLOUD_SERVERS: Record<string, string>;
export const DEFAULT_CLOUD_REGION = 'Australia';

export interface CloudDeviceInfo {
  name: string;
  mac: string;
  key: string;
  model?: string;
  version?: string;
  online: boolean;
  parentMac?: string;
  mid?: string;
}

export interface CloudHome { id: number; name: string; }
export interface CloudCredentials { userId: number; token: string; }

export type FetchLike = (url: string, init: { method: string; headers: Record<string, string>; body: string }) =>
  Promise<{ ok: boolean; status: number; statusText: string; json(): Promise<unknown> }>;

export function md5(input: string): string;
export function formatTimestamp(date: Date): string;              // UTC 'YYYY-MM-DD HH:MM:SS'
export function hashPassword(password: string, t: string): string;
export function buildBody(payload: Record<string, unknown>, date: Date, hashProps: string[]): Record<string, unknown>;
export function encryptBody(data: string): string;                // returns base64
export function decryptBody(base64: string): string;

export class GreeCloudApi {
  constructor(region: string, username: string, password: string, fetchImpl?: FetchLike, now?: () => Date);
  login(): Promise<CloudCredentials>;
  getHomes(): Promise<CloudHome[]>;
  getDevices(homeId: number): Promise<CloudDeviceInfo[]>;
  getAllDevices(): Promise<CloudDeviceInfo[]>;                    // all homes, concatenated
}
```

Behaviour rules:

- The constructor throws `Error('Unknown cloud region: <region>')` for a region not in the table.
- `fetchImpl` defaults to the global `fetch`; `now` defaults to `() => new Date()`.
- `getHomes` and `getDevices` throw `Error('Not signed in')` if called before `login`.
- A non-OK HTTP response throws `Error('HTTP <status> <statusText>')`.
- A sign-in reply with `r` present and not 200 throws `Error('Cloud sign-in failed: <msg or "unknown error">')`.
- String fields from device records are trimmed. `online` is `true` unless the record's `online` is `0` or `false`. Empty `pmac` becomes `undefined`. `mid` is stringified.
- No error message may contain the password, the token or a device key.

**`src/cloud/cloudProbe.ts` (command-line entry):**

- Usage: `node dist/cloud/cloudProbe.js [path-to-config.json]`, default path `/var/lib/homebridge/config.json`.
- Reads the config, finds the entry in `platforms` whose `platform` is `GREEAirConditioner`, reads its `cloud` object.
- If the platform, username or password is missing, prints one clear line saying which is missing and exits with code 2.
- Signs in, then prints `Signed in. Region: <region>.`, then one line per home with its device count, then one line per device in this exact shape:
  `<name> | mac=<mac> | model=<model or -> | ver=<version or -> | online=<yes|no> | parent=<parentMac or -> | mid=<mid or -> | key=<present|missing>`
- Ends with `Devices: <n>`.
- On any error prints `Probe failed: <message>` and exits with code 1.
- Must not print the username, password, token or any key value.
- Export the pure formatting function so it can be unit tested:
  `export function formatDeviceLine(device: CloudDeviceInfo): string;`
- The file must only run its main routine when executed directly, not when imported by a test. Use:
  `if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) { ... }`
